# 🕉️ Hindu Calendar & Live Panchang (Progressive Web App)

High-precision, offline-first Vedic Panchang and Hindu Calendar calculated with continuous trigonometric astronomical ephemeris algorithms.

Live Production Web App: [https://vikram-samvat-widget.vercel.app/](https://vikram-samvat-widget.vercel.app/)

---

## 🌟 Key Features

1. **Continuous Perpetual Ephemeris**:
   - High-precision continuous Lahiri Ayanamsha (`23.85° + 1.396° × T`).
   - Dynamic 5 Limbs: **Tithi**, **Vara**, **Nakshatra**, **Yoga**, and **Karana**.
   - Vikram Samvat, Shaka Samvat, Kali Yuga Year, Ritu & Ayana.

2. **24-Hour Muhurat & Choghadiya Matrix**:
   - All **30 Day & Night Muhurats** with exact start/end dates and times.
   - **24-Hour Choghadiya** (8 Day + 8 Night slots with Planetary Lords).
   - Strict Dharmic Color Standards: 🟢 **Green** (Auspicious), 🟡 **Yellow** (Neutral), 🔴 **Red** (Inauspicious).

3. **Interactive Date & Multi-Year Navigation**:
   - Inspect any date, month, and year across millennia.
   - 1-click **Live Real-Time Clock** toggle.
   - 30-day Monthly Tithi Almanac.
   - Dynamic Panchak Schedule for any year (e.g. 2024–2040+).

4. **100% Warning-Free PWA Installation**:
   - Direct standalone installation on **Windows**, **Android**, and **iOS**.
   - Zero antivirus / SmartScreen warnings.
   - Full offline support with Service Worker caching (`v3`).
